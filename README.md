# AppsScript_Mail
gli script che uso applicati in gmail

* Spam per nome non corretto (punteggiatura)

Gmail ignora quel che è scritto dopo il + (utile per separare messaggi) ma quando importa i messaggi normalizza anche la punteggiatura.
Se indirizzo è nome.cognome@ riceverà anche quelle indirizzate a nomecognome@

Anzi le normalizzerà rendendovi impossibile usare quel criterio come filtro dentro i programmi di posta.

Dopo una fase di monitoraggio con emailsenzapunto poi nel caso posso passare a spamsenzapassaredalvia.
Mi raccomando di modificare l'indirizzo di posta con il tuo.
